# 我把「知识短视频」做成了 30 套纯代码风格，开源了

刷完一晚上 AI 口播 / 幻灯片，你会发现：同一张脸、同一套转场、同一套「金句大字」。

我想要的是另一条路——**没有口播、没有真人出镜、一整条统一 BGM**，画面全程在动，知识本身就是视觉。

于是做了 **vibe知识**：选一个主题 + 选一种风格 → 纯代码渲出一条约 2 分钟的知识短视频。

仓库（MIT）：https://github.com/maomyu/vibe-knowledge

## 为什么是「纯代码」，不是模板套壳

- **skia-python → ffmpeg**：每一帧画出来，不是剪辑软件拖轨。
- **风格 = 视觉语法**：模板里不写死题材；文字、节奏、数据全进 `script.json`。
- **硬约束写进 skill**：零静止、一文一动、主字幕唯一、底栏 ≥2s 循序可读、音乐高潮锁画面、anti-strobe（不闪屏）。
- **先审后渲**：选题 + 全文案过目，再出片。

这不是「再套一层 Remotion 模板」——是把抖音知识片那种信息密度，压成可复现的渲染规范。

## 生产线长什么样

1. 选题（偏人性 / 大众心理 / 吸睛效应）
2. 全文案过审（约 520–580 字，成片约 115–130 秒）
3. 按风格 schema 写 `script.json`
4. 渲染 + density 自检（最长静止目标 0s）
5. 交付

开源仓含模板、schema、丰富度标准；**完整 BGM 不随仓分发**（版权自备）。
